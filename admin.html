Panel Admin

Gunakan Personal Access Token (PAT) GitHub Anda untuk masuk. Token hanya disimpan sementara di tab browser ini (sessionStorage) dan tidak pernah dikirim ke mana pun selain api.github.com.

Belum punya token? Buka GitHub → Settings → Developer settings → Fine-grained tokens, beri akses ke repo dengan izin Contents: Read and write.
